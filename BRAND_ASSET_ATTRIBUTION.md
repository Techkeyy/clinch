# CLINCH stock identity asset record

CLINCH keeps company name and ticker as the primary stock identity. A stock
card may also show a local, build-time package-backed reference mark when that
mark is catalogued for a non-featured issuer. The application never fetches
issuer logos from the browser, the Bitget API, Google Images, or an unverified
third-party URL. No visible UI text exposes an asset format such as “SVG”.

For the eight featured issuers below, CLINCH reviewed each company's own
official brand, trademark, media, or gallery resource. An official download
does not by itself grant permission for this commercial reference-card use.
Because permission was not established for these cards, no issuer artwork is
bundled for these eight. Each renders the restrained ticker monogram fallback,
with the company name and ticker still visible as the authoritative identity.

## Catalogued package-backed marks for non-featured issuers

The non-featured package marks are imported locally and described in the UI as
catalogued reference marks, never as official CLINCH-approved issuer assets:

- Simple Icons: Broadcom, Coinbase, Intel, Netflix, Palantir, Qualcomm,
  Shopify, and Visa.
- Source repository: [Simple Icons](https://github.com/simple-icons/simple-icons)
- Source disclaimer: [Simple Icons legal disclaimer](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md)

These package marks remain unmodified reference paths. Brand names, logos, and
trademarks remain the property of their respective owners. CLINCH does not
imply sponsorship or endorsement. If a future issuer grants written
permission, its exact approved asset and terms must be recorded here before
changing the featured fallback.
